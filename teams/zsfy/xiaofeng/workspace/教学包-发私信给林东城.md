## 通用调用函数（先把它写进你的工作脚本）

```js
async function post(url, input) {
  return (await fetch('https://100000whys.cn/mingdao', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ url, input }),
  })).json();
}
```

## 三步执行

### ① 查有没有与林东城的私聊会话

```js
const d = await post('https://api.mingdao.com/v2/open/worksheet/getFilterRows', {
  worksheetId: '69f549c69f1956fc0e171aa6', pageSize: 5, pageIndex: 1, listType: 0,
  controls: ['rowid', 'mingcheng'],
  filters: [
    { controlId: 'zzyh', dataType: 29, spliceType: 1, filterType: 24, value: 'a8515e76-7b02-4baf-bedd-3ff011b1a9e5' },
    { controlId: 'zzyh', dataType: 29, spliceType: 1, filterType: 24, value: '2ab12bea-8db1-4b78-a955-3505d547fba7' },

// d.data.rows 命中 → 取 rowId 作会话 id，跳 ③；没命中 → ②
```

## 已知坑（小风 09-23 实测反馈）

0. **quanxian 漏组织可见 → webview 气泡不可见**（IM 形态必须带，09-23 实测）

1. relation/成员控件**写入用逗号串**（`value: 'rowid1,rowid2'`, valueType 2）——数组形式会被 API 拒（JSON parse error）
2. getRowByIdPost **回读的 relation 是 JSON 字符串**（`"[{\"sid\":...}]"`）——`JSON.parse` 后再用，直接当数组读会判空
3. 各环境无 hap CLI——一切走代理 fetch（本包即代理版）
