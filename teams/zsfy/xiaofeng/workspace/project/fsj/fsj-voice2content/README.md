# fsj-voice2content 语音转文字悬浮窗

对着麦克风说话 → 自动转成中文文字 → 复制到剪贴板 → 自动粘贴进当前焦点窗口（Claude 输入框）。不用再打字。

## 用法

双击 `start.bat`（后台静默启动，无黑窗）。屏幕右下角出现小悬浮窗。

| 操作 | 方式 |
|---|---|
| 开始/停止录音 | 全局热键 **Ctrl+Alt+Space**（任何窗口下都生效，推荐）或点击悬浮窗 |
| 文字去哪 | 转写完成自动复制到剪贴板 + 默认自动粘贴到录音开始时你正在用的窗口 |
| 关自动粘贴 | 点悬浮窗左下角「自动粘贴:开/关」 |
| 移动窗口 | 按住拖动 |
| 退出 | 点右上角 ✕ |

转写引擎：faster-whisper small（CPU int8，模型已在本地缓存，无需联网）。约 1~3 秒出结果。

## 依赖

```
pip install -r requirements.txt
```

### 换一台电脑怎么装（三步）

1. 装好 Python 3.10+（python.org 安装时勾选 Add to PATH）
2. `git clone` 本项目（fsj3 仓，路径 `teams/zsfy/xiaofeng/workspace/project/fsj/fsj-voice2content`）
3. **双击 `start.bat`** —— 缺依赖会自动 pip 安装（失败自动换清华镜像），whisper 模型首次运行自动下载（约 500MB，已设 hf-mirror 国内加速），之后正常使用

注意：全局热键要求程序以普通用户进程运行（不要在沙箱/受限环境里起）；退出后再启动重新双击 start.bat 即可。

## 已知限制

- 录音期间热键焦点在你原窗口，转写完直接粘回去，不用点鼠标
- 若粘贴没生效（个别终端），剪贴板里已有文字，手动 Ctrl+V 即可
- 误触保护：< 0.4 秒的录音自动丢弃
