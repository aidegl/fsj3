# wxApp-youqu 小程序部署配置指南

> 本项目是 webview 壳小程序模板，每个商家/品牌部署一个独立的小程序版本。

---

## 一、必须修改的配置

### 1. 微信小程序配置 `project.config.json`

**文件**: `project.config.json`

```json
{
  "appid": "这里填你自己的小程序AppID",
  "projectname": "你的项目名称"
}
```

- `appid` — 在微信公众平台（https://mp.weixin.qq.com）→ 开发管理 → 开发设置 中获取

### 2. 小程序登录配置 `app.js`

**文件**: `app.js`，第 73 行

```javascript
data: {
  code: loginRes.code,
  appid: 'wxef28e4600201b359',       // ← 改成你的小程序 AppID
  secret: '24ebdf5b5b2cd7c6697d782ca1ba019a'  // ← 改成你的小程序 AppSecret
}
```

| 配置项 | 说明 | 获取位置 |
|--------|------|---------|
| `appid` | 小程序 AppID | 微信公众平台 → 开发管理 → 开发设置 |
| `secret` | 小程序 AppSecret | 微信公众平台 → 开发管理 → 开发设置 → 开发者密码（需管理员重置） |

> ⚠️ **AppSecret 只显示一次**，请妥善保存。如果忘记，需要管理员在公众平台重置。

### 3. 微信支付配置 `app.js`

**文件**: `app.js`，第 10~14 行

```javascript
globalData: {
  payConfig: {
    appid: 'wx022fc6b610cfa5b4',          // ← 小程序 AppID（与上面一致）
    mch_id: '1709556093',                 // ← 微信支付商户号
    api_key: 'shuxiaohe022577wuweiqiluanyunshu'  // ← 微信支付 API 密钥
  },
  // ...
}
```

| 配置项 | 说明 | 获取位置 |
|--------|------|---------|
| `appid` | 小程序 AppID（同上） | 微信公众平台 |
| `mch_id` | 微信支付商户号 | 微信支付商户平台（https://pay.weixin.qq.com）→ 账户中心 |
| `api_key` | 微信支付 API 密钥（32位） | 微信支付商户平台 → 账户中心 → API安全 → API密钥 |

### 4. WebView 地址配置 `pages/webview/index.js`

**文件**: `pages/webview/index.js`，第 11~12 行

```javascript
// ========== 开发测试：切换到本地 webview ==========
USE_DEV_URL: true,
DEV_URL: 'https://100000whys.cn/fsj_webview2.0/?shangjia=9cb358a8-620a-4fc7-970a-cf10aa2173d9',
// =================================================
```

**正式发布后**，把 `USE_DEV_URL` 改为 `false`：

```javascript
USE_DEV_URL: false,
```

| 配置项 | 说明 |
|--------|------|
| `USE_DEV_URL` | `true` = 开发模式使用 DEV_URL；`false` = 使用默认生成逻辑 |
| `DEV_URL` | 开发模式下 webview 加载的地址，`shangjia` 参数是商家的 rowid |

第 92 行的默认 base URL 也需要同步修改：

```javascript
var base = 'https://100000whys.cn/fsj_webview2.0/?shangjia=9cb358a8-620a-4fc7-970a-cf10aa2173d9';
```

### 5. 支付回调地址 `pages/webview/index.js`

**文件**: `pages/webview/index.js`，第 219 行

```javascript
notify_url: 'https://100000whys.cn/fsj/api/pay/notify'
```

根据你的实际后端地址修改。

## 二、配置检查清单

每个新商家部署前，逐项确认：

- [ ] `project.config.json` → `appid` 已改为新小程序的 AppID
- [ ] `app.js` → 登录 `appid` / `secret` 已改为对应值
- [ ] `app.js` → `payConfig` 已配置商户号和 API 密钥
- [ ] `pages/webview/index.js` → `DEV_URL` 的 `shangjia` 参数已改为商家 rowid
- [ ] `pages/webview/index.js` → 第 92 行 `base` URL 的 `shangjia` 参数一致
- [ ] 后端 code2session 接口能正确接收 `appid` + `secret` 参数

---

## 三、登录原理说明

```
wx.login() → 生成 code（绑定小程序 AppID）
    ↓
POST /fsj/api/user/code2session
  data: { code, appid, secret }
    ↓
后端用 appid + secret 调用微信 jscode2session
    ↓
返回 openid → 登录成功
```

**关键**：`wx.login()` 生成的 code 和请求中的 `appid` 必须匹配，否则微信会返回 `invalid code`。
