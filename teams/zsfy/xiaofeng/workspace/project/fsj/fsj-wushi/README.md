# fsj-wushi 五事系统

> Agent 12 维数据的可视化维护工具——「五事」骨架（道/天/地/将/法 + 时间记事）的层级树管理。
> 参考：objectives-management-system 的 UI（左树 + 右详情），去掉中间看板。
> 创建：2026-09-03｜状态：文档阶段

---

## 一句话定位

一个**零依赖原生 JS 单页**：按发布者（agent）过滤 shangpin 内容元数据，以「五事骨架」为根渲染 12 维层级树，支持节点增删改、12 维着色、拖动排序、行内编辑——给每个 agent 一个看得见摸得着的"数据人生"。

## 快速运行

```bash
cd fsj-wushi
npx http-server -p 8090 -c-1
# 浏览器打开 http://localhost:8090
```

数据接口：复用服务器常驻代理 `https://100000whys.cn/obj`（hap-proxy，pm2 守护），**本地零进程依赖**。

## 核心特性

| 特性 | 说明 |
|------|------|
| Agent 切换 | 顶部下拉，按 `fabuzhe` 过滤 shangpin |
| 视图切换 | 顶部「编辑详情 / 权重必读」下拉（2026-10-04）：编辑详情=原有行为；权重必读=右侧变 100 格必读板 |
| 权重必读板 | 管理 agent 必读段（load-always 数据源）：100 格、格子权重 10000 起步长 1 递减；点格子选中→点左树节点→「置入」（覆盖式）；拖到空格=移动、拖到有内容格=互换；选中可删除/查看详情（wznr 全文+备注编辑）；底部保存=必读 JSON 写回「必读权重-\<agent\>」记录 wznr + 各节点 quanzhong=格子权重（移除恢复 0）。用户表 bdwznr 由 HAP 关联自动镜像，页面不直写。未保存改动切视图/切角色弹确认 |
| 12 维着色 | 树节点按 `sew` 维度显示专属颜色（见 docs/12维颜色.json） |
| 层级树 | 五事骨架（道天地将法+时间记事）为骨架，fu/zi 父子链展开 |
| 行内编辑 | 详情面板直接改，失焦/变化自动保存 |
| 物理删除 | 走 hap-proxy deleteRow（不可恢复） |
| 拖拽移动 | 三分区拖拽（参考 objectives-management-system）：上 1/3 插前面、中 1/3 **拖入成为子项**（目标高亮发光）、下 1/3 插后面；支持同层排序与跨层移动（自动改写 fu），骨架节点仅限本层排序，防环检测 |
| 完成标记 | wancheng="1" → 节点名划线 |
| 完全引用标记 | `wqyy` 非空 → 标题左侧紫色「引」徽标；详情正文只读显示 `wqyywznr`（随所引记录自动同步，2026-09-21 接入） |

## 必读清单 JSON 格式 v1（「必读权重-\<agent\>」记录 wznr 字段）

```json
[
  { "rowid": "<内容元数据 rowid>", "shuoming": "一句话：这条为什么在必读里" }
]
```

- 条目**只有两个字段**；名称/正文/权重等一切细节经 rowid 现查（skeleton-cache node 或页面 api），绝不冗余存储
- 数组顺序 = 格子顺序 = 加载顺序（顶部权重 10000，递减至 9901，全部落在 load-always 的 [9900, 10000] 必读段）
- 存储：用户表（每 agent 一条记录）`bidu` 关联字段 → sid 指向「必读权重-\<agent\>」记录；`bdwznr` 文本字段由 HAP 关联自动镜像
