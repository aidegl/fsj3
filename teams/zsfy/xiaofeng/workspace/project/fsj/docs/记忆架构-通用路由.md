## 三、权重 × 搜索行为（核心规则）

| 权重档 | 搜索行为 | 说明 |
|---|---|---|
| 0~2 分 | **不进搜索策略** | 临时想法/低频片段，默认搜不到 |
| 3 分 | **进搜索** | 默认数据（新创建），需要被检索到才有反馈检验 |
| 4 分 | 进搜索 | 按需 |
| 5 分 | **必搜** | 常用成熟数据 |
| 6~8000 分 | **必搜区间** | 分数越高越重要；10000 往下的 n 条可设必搜，数量 agent 自定 |
| 8001~9000 分 | **临时小抄**：免路由全量缓存直读（rowid/mingcheng/miaoshu）≤100 条 | agent 每隔一段时间编排的数据；用前核对 miaoshu 场景任务匹配，匹配再通过 rowid 找 wznr |
| 9001~9900 分 | **必读小抄**：免路由全量缓存直读（rowid/mingcheng/miaoshu）≤100 条 | 每轮都要用到的高频内容，稳定常用的有价值数据 |
| 9901~10000 分 | **必读权重**：免路由全量加载（+wznr）每轮必读 | 最重要的规则、路由以及经常要用且稳定的内容 |

> **防压缩规则（CLAUDE.md 声明）**：必读权重 / 必读小抄 / 临时小抄 三档为防压缩内容——上下文一旦压缩，立即按 rowid 重新全量加载一次（必读权重档含 wznr）。

> 搜索命中率反过来喂权重：常被命中且有用的升档（3→5），长期不命中的降档（5→3），升/降档在 12 维复盘时批量操作。

## 四、搜索策略语法（模板）

HAP 搜索过滤器模板（照抄改字段）：

```
((((k:A)((v:A)((f:[mingcheng,2,1,2,技能];[sew,2,1,2,技能])))((r:A)))
```

- `k` = 关键词模式 · `v` = 值匹配 · `f:` = 字段过滤（`[字段,权,?,匹配值]` 数组可多条 `;` 分隔）· `r` = 范围
- 组合规则：条件从左往右包一层，返回结果为满足全部条件的记录集
- 使用纪律：**先小范围验证一条策略，确认命中合理后再复制扩展**——盲写的复杂策略容易静默漏召

## 六、命中率（每次检索必记）

```
{"t":"HH:MM","agent":"无名","q":"查询原文","way":"语义|关键词|骨架|路由|本地记忆","hits":5,"top1":"命中标题","rel":4,"miss":false,"歪排":false}
```

- rel 五档：5 就是我要 / 4 有帮助 / 3 沾边 / 2 同域不相关 / 1 完全无关
- **miss:true 是金子**：该找到却没找到必须标，直接指向入库缺口
- 纯聊天/巡检/跑命令不记

## 八、睡眠机制（0 点批量上云 = 入睡 → 做梦 → 醒来）

> 认知原型：白天海马体记情景流水，睡眠时重放并按相似性归并进长期记忆——不靠逻辑推理，靠取象比类。

| 阶段 | 时点 | 干什么 |
|---|---|---|
| **入睡** | 0 点定时任务触发 | 收白天缓存：计划流事件 / buffer / 临时小抄新增 / 命中日志 |
| **做梦** | 同任务内加工 | ① 重放：逐条过白天事件 ② **取象比类**：LLM 相似性归堆，挂 12 维 / 权重初值 ③ 拿不准的 → 梦呓区 ④ 命中统计 → 批量升降权重 |
| **醒来** | 白天 agent 复盘 | 读梦境报告，只审梦呓区，其余默认成立 |

### 护栏
1. 梦的产物全部可审计（梦境报告逐条列出处）
2. 拿不准的永不静默入库（进梦呓区，白天人工定夺）
3. 幂等：已上云事件打标记，不重复
4. 取象比类的 LLM 归堆策略 = M2 待设计，本章节先定机制与术语

### 术语
- **做梦**：上述加工过程 · **梦呓区**：低置信待审清单 · **梦境报告**：做梦产出的审计报告
