# 上帝端 PRD

> 本文档回写自 9-05 以来的实际开发（欠账清偿 s34），描述上帝端「是什么、给谁用、做到哪了」。技术细节见 [[功能文档]]，未拍板事项见 [[任务列表-HAP真数据-方案]]。

## 一、产品定位

**上帝端 = 东城的一屏总览指挥台**。手机派活、agent 执行、计划流推进——所有状态在一个 PC 网页实时可视，老板不用问「现在干到哪了」，看一眼就知道。

- 服务对象：东城（唯一重度用户），agent 们（读自己的行动行/情绪反馈）
- 数据源：计划流 flow JSON（15步标尺+子步）、loopstate 行动行、命中率日志、（拍板后）HAP 真数据
- 技术形态：原生 HTML+mermaid 渲染，Node 静态服务 + SSE/WebSocket 推送，fs.watch 驱动实时刷新

## 二、已交付功能（按里程碑）

### M1 基础可视化（9-05~9-20）
- 计划流渲染：mermaid 流程图 + 步骤状态（todo/running/done/blocked 四态，未完成沉底）
- sdetail 明细面板 + 跟随单例（执行中居中聚焦，完成后停在最近完成步）

### M2 可见性修复冲刺（10-19~10-20）
- 数据重置+server 指针自动取最新 flow（防硬编码过期）
- 变更行闪烁（.flash 2s 脉冲）——改了哪一眼看到
- 白三角指针：随执行步跳动；任务列表=plan steps（键名 tasks→steps 修复）
- 情绪系统：九脸+emo 驱动角色动画（执行中带 emo 即播；开心缺 emoji 修复；情绪只在结束时刻写）
- 左栏 ptabs 扩至 8tab（技能+价值合并为准则，grid 2×4）
- 检索透明化：demoHits/行动行标【方法·端点·耗时】；真实检索自动表格；三形态状态机（检索→情绪→流程图）实测

### M3 协议与路由（10-20~10-21）
- 搜索路由 tabs：必读/情绪/八格/通用/智能 + webSearch 选项；八格 mermaid 代码库（routes.json 驱动，只列标题不渲染图）
- 协议壳升级 (((s:)))： Obsidian wikilink 兼容（[[[ ]]] 会撞链接语法）
- emoji-map.json（16 情绪，常用前置）+ emoji-table.html 极简查看器
- s2 补账：流标题 sticky、字号统一、双标题去重、小三角逻辑、跟随按钮
