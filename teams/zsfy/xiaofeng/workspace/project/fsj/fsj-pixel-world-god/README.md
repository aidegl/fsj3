# 像素视界上帝端（fsj-pixel-world-god）

> PC 网页端的"造物主视角"——俯瞰整个像素世界如何运转。
> 状态：**v2 实装运行中**（2026-10-19 起每日实战迭代，功能明细见 docs/功能文档.md）
> 手机端（姊妹项目）：[../fsj-pixel-world/](../fsj-pixel-world/)

---

## 一句话定位

**不扮演任何角色，只看世界本身**：一屏俯瞰天界五行局的实时运转——谁在哪、谁在动、哪里有人气，点击任意场景放大细看，点击任意角色查看其资料。手机端是"走进世界"，上帝端是"俯瞰世界"。

## 为什么独立目录

- 用户（东城）拍板：独立项目、独立入口，与手机端互不干扰
- **模块不复制**：渲染调色板、WS 客户端、世界配置加载等直接跨目录 ES module 引用手机端源码（同源部署），单一数据源不分叉（见技术方案 §2）
- PC 大屏交互（多窗格、鼠标悬停、大画布）与手机触屏差异大，强行塞进手机端会互相拖累

## 冒烟清单（东城 5 分钟过一遍）

1. 打开 `index.html`（live preview 或部署后同域访问）→ **默认直接进入天孚宫地图**，无任何总览层
2. 顶栏：地图下拉（有地图的场景可选，无地图的置灰）、聚焦角色下拉、`● 实时`（绿）、时钟、统计
3. **移动地图**：按住方向键（↑↓←→）平移；或按住空格（光标变抓手）+ 鼠标拖动
4. **缩放**：滚轮（锚定鼠标位置）
5. **聚焦下拉**：选一个角色 → 相机居中到 TA + 五行色描边 + 资料卡打开；下拉列出当前地图全部角色
6. 悬停角色出名牌（名字/职位/等级/实时性）；点角色出资料卡
7. 地图下拉切到「土局」→ 地图切换，聚焦下拉自动刷新为土局内角色
8. 手机端同账号走两步 → 上帝端 ≤2s 跟随（实时）；断网 30s 恢复后位置自动对账
