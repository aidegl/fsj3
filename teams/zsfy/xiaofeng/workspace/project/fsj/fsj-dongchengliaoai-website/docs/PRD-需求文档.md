# fsj-dongchengliaoai-website · PRD 需求文档

> 版本 v1.0｜2026-10-08｜撰写：无名｜产品拍板：林东城
> 定位：**粽说风云官方网（东城聊AI）**——自媒体粉丝的资源整合入口
> 技术路线：原生三分离（零依赖零构建）· 手机优先响应式 · 宝塔 nginx 部署

---

## 一、一句话定位

**「东城聊AI」商家宇宙的自定义 storefront**：粉丝从这里认识林东城、学课程、进社群、看 AI 理念——所有内容长在 fsj 内容元数据表里，官网是它的定制皮。

## 二、背景与架构定位

| 决策 | 内容 |
|---|---|
| 商家宇宙 | 本项目在 fsj 体系内新建一个**商家**（东城聊AI），享有独立的成员/内容/配置——"商家即宇宙" |
| 数据复用 | 课程/文章/资源全部存**内容元数据表**（shangpin），`leixing` 区分类型，`shangjia` 关联本商家——**不建新表** |
| 参照项目 | webview-spa2.0（SPA 框架 + fsj 表结构的既有实践）；本项目 UI 全新定制，数据层沿用其通道与规范 |
| 技术栈 | 原生 HTML/CSS/JS 三分离（老板拍板），零构建零框架 |
| 放弃像素风 | 官网为**高清素材风格**（AI 生成场景图/立绘已验证可行），与像素世界（存量资产养老）双轨并存 |

## 三、目标用户与场景

| 用户 | 场景 |
|---|---|
| 自媒体粉丝（手机为主） | 从视频/公众号点进来 → 认识东城 → 看课程 → 扫码进社群 |
| 老粉 | 回来查资源、看 AI 理念更新 |
| 潜在合作方 | 了解东城的能力与理念 |

## 四、四大板块

| 板块 | 内容 | 数据源 | 交付方式 |
|---|---|---|---|
| **课程** | 课程卡片（封面/标题/简介），点击**跳转学浪**成交交付 | 内容元数据 `leixing=课程`（或独立维护清单） | 外跳学浪链接 |
| **我的介绍** | 东城个人 IP 页：经历/理念/成绩/联系方式 | 静态内容 + AI 高清形象 | 站内 |
| **资源与社区** | 现有社群导流（二维码/链接）+ 资源清单 | 静态维护 | 站内展示 |
| **AI 理念** | 社区页面形态：**理念帖流**（决策流/天道/八神谱等成果的故事化呈现） | 内容元数据 `leixing=文章`（fabuzhe=东城/无名） | 站内阅读 |

## 五、页面结构（SPA，手机优先）

```
首页 index
├── Hero：东城聊AI · 一句话价值主张 + CTA（看课程/进社群）
├── 课程区：课程卡片流 → 点击外跳学浪
├── 介绍区：林东城 IP 卡片 → 详情页
├── 资源与社区：社群入口卡 + 资源清单
├── AI 理念：理念帖流（内容元数据 文章类）
└── 页脚：联系方式 · 备案 · 友情链接
详情：课程详情页 / 文章详情页（按 rowid 现查渲染）
```

## 六、技术架构

| 项 | 选择 |
|---|---|
| 架构 | 原生三分离 SPA（零构建），参照 webview-spa2.0 的路由与数据层模式 |
| 读 | Node 代理 /mingdao（匿名读公开内容，密钥服务端注入） |
| 写 | 本期无写操作（纯展示官网，无登录无评论） |
| 部署 | 宝塔 nginx 静态目录 + 域名（待定） |
| 素材 | AI 生成（MiniMax 已验证）+ Figma 排版 |

## 七、里程碑

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| M1 | 骨架 + 首页（Hero/课程区/介绍区/页脚） | 手机打开首屏完整 |
| M2 | 课程详情页 + 学浪外跳 + 资源社区板块 | 四板块全通 |
| M3 | AI 理念帖流（读内容元数据 文章类） | 理念页动态渲染 |
| M4 | 视觉精修（AI 场景图/品牌色）+ 部署上线 | 域名可访问 |

## 八、非目标（本期不做）

- 站内登录/注册/支付（课程外跳学浪完成闭环）
- 站内评论/发帖（社区导流现有社群）
- 后台管理（内容直接维护在 HAP，官网实时读）
- PC 深度适配（手机优先，PC 保证可用即可）

4. Lighthouse 手机版性能 ≥ 90；PC 可用无错位
5. 全站无控制台红错
