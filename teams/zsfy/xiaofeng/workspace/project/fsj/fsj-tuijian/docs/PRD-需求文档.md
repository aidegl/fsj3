# PRD · 推荐页（fsj-tuijian）

> 抖音式内容推荐页 · 小程序内嵌 webview SPA · Stage 1 样式先行

---

## 1. 业务背景

fsj 平台需要一个核心分发入口 —— 用户进入后无目的浏览，由推荐系统决定看到什么内容。参考抖音的"竖滑 + 一次一卡"形态，适配 fsj 现有的内容池（图文 + 视频 + 纯文字）。

---

## 2. 用户故事

| 角色 | 故事 |
|------|------|
| 用户 | 我打开小程序，能立即看到一条内容，不需要选类目或搜索 |
| 用户 | 我上滑看下一条，下滑回上一条，操作要跟手 |
| 用户 | 看到喜欢的，我可以点赞、收藏，等以后回看 |
| 用户 | 看到不喜欢的，我能"不感兴趣"，下次少推给我 |
| 用户 | 视频自动播放，不用我点；图片/文字静止看 |
| 用户 | 评论/分享/关注作者，是我表达的方式 |
| 用户 | 看作者是谁，喜欢点，决定合作，点头像能看主页 |

## 3. 交互流程

### 3.1 滑动切换

```
[卡片A]
   ↓ 上滑 (translateY < -80px)
[卡片B]  ← 卡片A 滑出顶部，卡片B 从底部入场
   ↓ 上滑
[卡片C]
   ↑ 下滑 (translateY > +80px)
[卡片B]  ← 卡片A 从底部回升入场
```

参数：
- 触发阈值：80px（小于此值弹回）
- 动画时长：300ms ease-out
- 边界：第一条下滑无效，最后一条上滑无效

### 3.2 视频播放

- 进入可见：自动播放（静音）
- 离开可见：暂停
- 单击：播放 ↔ 暂停
- 双击：点赞 + 飞出 ❤️ 动画（Stage 1 仅触发点赞状态）
- 进度条：底部细条（Stage 1 占位）

### 3.3 互动组件（右侧悬浮栏）

| 按钮 | 行为 | Stage 1 状态 |
|------|------|--------------|
| ❤ 点赞 | 切换点赞 + 计数 +1/-1 | 本地 Map |
| 💬 评论 | 弹评论面板 | 仅壳子 |
| ⭐ 收藏 | 切换收藏 + 计数 +1/-1 | 本地 Map |
| ➤ 分享 | 调 `navigator.share` 或 toast | mock |
| ✕ 不感兴趣 | 加入黑名单 + 自动跳下一条 | 本地 Set |

### 3.4 作者栏（底部）

| 元素 | 行为 | Stage 1 状态 |
|------|------|--------------|
| 头像 | 点击跳作者主页 | toast mock |
| @name | 点击跳作者主页 | toast mock |
| +关注/已关注 | 切换关注 | 本地 Set |
| 推荐标题 | 静态展示 | — |

### 3.5 评论面板

- 从底部弹出（高度 70%）
- 标题：X 条评论
- 内容：占位（"暂无评论"）
- 输入框：禁用（placeholder: 发条评论吧（mock））
- 关闭：右上角 × 或点击遮罩

## 4. 内容类型规格

### 4.1 video（视频卡片）

- 占满整屏
- `<video>` 标签，object-fit: cover
- 静音自动播放 + 循环
- 必需字段：url, coverUrl, duration, width, height
- 兼容属性：playsinline / webkit-playsinline / x5-playsinline（兼容小程序 webview）

### 4.2 image（图文卡片）

- 多张图垂直堆叠（scroll-snap）
- 占满整屏
- 必需字段：images[]（1-3 张 URL）

### 4.3 text（纯文字卡片）

- 居中显示
- 背景色可配
- 字段：textBlocks[]（type: h2/p）, backgroundColor

---

## 5. 不在范围（Stage 1 之外）

- 视频上传/编辑
- 评论编辑器
- 作者主页内容（点击只 toast）
- 关注关系链同步（只本地状态）
- 用户登录态集成
- 真实推荐算法（mock 数据固定顺序）
- 视频预加载优化
- 错误边界（断网/视频 404 等的友好降级）
