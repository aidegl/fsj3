## 2. 模块职责

### 2.1 Page（pages/tuijian/index.js）

核心状态：
```javascript
class Page {
  // 数据
  items = [];              // 内容数组
  currentIndex = 0;         // 当前卡片索引

  // 互动状态
  likedMap = {};           // 点赞 Map<id, true>
  collectedMap = {};        // 收藏 Map<id, true>
  followedSet = new Set(); // 关注作者
  dislikedSet = new Set(); // 不感兴趣
}
```

职责：
- 加载页面骨架 + 初始化子组件
- 维护全局状态
- 协调子组件 update
- 处理滑动逻辑
- 处理互动回调

### 2.2 TuijianCard

根据 `item.type` 渲染三种视图：
- `video` → `<video>` 全屏 + 自动播放
- `image` → 图片垂直堆叠 + scroll-snap
- `text` → 居中文字 + 背景色

提供 `update(item)` 切换内容时调用。

### 2.3 ActionBar

右侧悬浮按钮组：
- ❤ 点赞 / 💬 评论 / ⭐ 收藏 / ➤ 分享 / ✕ 不感兴趣
- `update({ item, liked, collected })` 切换状态

### 2.4 AuthorBar

底部作者栏：
- 头像 / @name / +关注 按钮 / 推荐标题
- 关注状态切换

### 2.5 VideoPlayer

`<video>` 标签封装：
- `play()` / `pause()` / `togglePlay()`
- 自动播放失败时静默忽略（需用户交互）
- `destroy()` 释放资源

### 2.6 CommentSheet

底部弹出的评论面板：
- `init()` 渲染并绑定事件
- `destroy()` 移除 DOM

## 3. 滑动实现细节

### 3.1 方案

**自实现 touch + mouse 事件**，不依赖 scroll-snap。

理由：
- 控制力强（动画时长、阈值、边界）
- 桌面端调试友好（mouse 拖拽）
- 避免 scroll-snap 在某些 webview 的兼容问题

### 3.2 关键参数

| 参数 | 值 | 说明 |
|------|----|----|
| SWIPE_THRESHOLD | 80px | 触发切换的最小距离 |
| SWIPE_MAX_DRAG | 200px | 拖拽时的最大偏移（防止过度） |
| SWIPE_DURATION | 300ms | 切换动画时长 |

### 3.3 流程

```javascript
// 触摸开始
touchstart → touchStartY = y, isDragging = true

// 触摸中
touchmove → dy = y - touchStartY, transform: translateY(dy)

// 触摸结束
touchend →
  if (|dy| < 80px) → translateY(0)（弹回）
  if (dy < -80px && hasNext) → translateY(-100%) + 切换到下一条
  if (dy > +80px && hasPrev) → translateY(+100%) + 切换到上一条
```

### 3.4 切换逻辑

```javascript
// 1. 滑出动画 300ms
cardEl.style.transform = 'translateY(-100%)'

// 2. 动画结束后（300ms 后）
//    - 暂停旧视频
//    - 重置 transform 到 100%（无视觉跳动，因新卡片从底部进入）
//    - 渲染新卡片
//    - 复位 transform 到 0
```

## 4. 视频自动播放策略

### 4.1 限制

浏览器/小程序 webview 自动播放策略：
- 必须 **静音**（muted=true）
- 用户首次交互后才能带声

### 4.2 实现

```javascript
// 进入可见
videoEl.muted = true;
videoEl.play(); // 可能被浏览器拦截，catch 即可

// 离开可见
videoEl.pause();

// 单击切换播放
videoEl.addEventListener('click', () => {
    if (isPlaying) pause();
    else play();
});
```

### 4.3 小程序 webview 兼容

`<video>` 属性必加：
- `playsinline`
- `webkit-playsinline`（iOS 兼容）
- `x5-playsinline`（微信 X5 内核）
- `x5-video-player-type="h5"`（强制 H5 播放器）

## 5. 样式规范

### 5.1 rem 适配

- `html { font-size: 100px; }`（基于 750px 设计稿）
- 所有尺寸用 rem（`1rem = 100px`）
- 例：`width: 0.5rem` = 50px = 设计稿 100px ÷ 2

### 5.2 命名约定

- 文件：`kebab-case.html/css`，class：`PascalCase` 或 `kebab-case`
- CSS 不引入 CSS Modules / Tailwind 编译版（用 CDN 内置 utility）

### 5.3 暗色优先

整体深色风格（黑底白字），匹配抖音视觉。

---

## 6. 缓存策略

继承 `webview-spa-template` 三层禁用：

1. **HTML meta**：Cache-Control / Pragma / Expires
2. **URL 版本号**：`?v=__VERSION__`，每次 Date.now()
3. **fetch no-store**：所有 fetch 加 `{ cache: 'no-store' }`

---

## 7. 性能注意点

### 7.1 视频

- 仅当前 + 相邻卡片加载视频源
- 离开可见立即 pause
- 切换时 destroy 旧 VideoPlayer（释放 src）

### 7.2 图片

- `loading="lazy"`
- `object-fit: cover` 避免变形

### 7.3 DOM 更新

- 卡片切换用 innerHTML 重渲染（30 条量级无压力）
- 子组件 update 时不重建 container，只更新内容
