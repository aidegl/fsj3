# 像素世界 2.0 · 使用手册

> 角色即格子 · 一格 64×64 · 素材即数据 · 数据只存一份（HAP 权威，本地缓存）

## 开始

1. 新会话先读本手册 + `README.md`（里程碑与决策记录 §八）。

## 核心概念（术语表）

| 术语 | 定义 | 大白话 |
|---|---|---|
| 格子 | 64×64 px 的世界最小单位，场景 48×48 格 | 停车场的一个车位 |
| tx/ty | tile 坐标（格坐标），角色权威位置 | 你停在第几排第几个车位 |
| wx/wy | 世界像素坐标 = tx×64, ty×64 | 距入口多少米（仅渲染用） |
| 角色占 1 格 | 占格不独占：目标格有人可重叠，路过避让 | 车位可合停，进出让行 |
| 碰撞 collision[y][x] | 1=墙 0=可走，地图属性不资产化 | 地下埋的 0/1 名单 |
| BFS 寻路 | 水波扩散找最短路，四方向 | 撞墙绕行的笨办法（小图够用） |
| xsdt | 场景数据：tiles 瓦片库 + layers(ground/decor/collision) + spawns + entrances | 一张地图的全部档案 |
| 地点树 | 区→单元→层（fu/zi 组树）+ 三界 sanjie | 省→市→街道行政区划 |
| z 层 | 地皮-100 → 角色 0 → 装饰自定；遮挡靠素材透明部分 | 透明玻璃片叠放 |
| 帧/帧表 | 动画一帧=64×64（或立绘 192×384）；帧表 JSON 记坐标时长 | 连环画的每页+页码表 |
| 描边 | 彩色格邻接透明 → 181818，外圈必压黑 | 剪纸的外轮廓线 |
| 发影 | 头发正下方皮肤格加深（如 FF9F50） | 刘海下的阴影 |

## 素材生产工序（每道：入口/准备/步骤/输出/注意）

### 工序 1 · 参考图 → 40×40 角色（+黑描边/对称/嘴）

- 工具：`tmp-api/sps.py`（吸附）+ `tmp-api/craft40c.py`（工艺）
- 准备：任意图（JPEG 先用 GDI+ 转 PNG；超大先降采样 ≤512）
- 步骤：`python sps.py <图> <输出> [- <目标网格>]` → 检测/指定网格 → 按格主色 → `craft40c.py` 对称化+合成嘴+描边 → x3 放大居中 40×40
- 输出：40×40 PNG + x8 预览
- 注意：**解码必须用带滤镜处理的版本**（无滤镜版会把图读成彩虹噪点，历史事故两次）；非整数步长靠主色取样保证格子干脆

### 工序 2 · 地皮素材 → 无缝平铺

- 工具：MiniMax 生 1024 → `tmp-api/make-seamless2.ps1`（错位+十字融合）→ 96 成品
- 注意：融合带 96px；成品必做 3×3 平铺接缝检查（Figma 展示组模式）；风格锚 = 老板 PS 定稿版

### 工序 3 · 概率模板生成角色

- 数据：`{geshi:"fsj-pixel-gailv-v2", mingcheng, didian:"biaozhun.pixels_xiao[0]", edits:{"r,c":[{yanse,gailv,beizhu}]}}`
- 规则：只存人工定义的格；概率合计<100 剩余回退底稿原色；yanse:null=覆盖透明；未定义格=底稿原样
- 模板：`测试/角色概率-参考图特征版.json`（小风绿裤样例）

### 工序 4 · 序列帧 → 精灵图（定稿打包）

- 工具：`tmp-api/pack-sheet.ps1 <帧目录> <sheet.png> <frames.json> [列数] [fps]`（**待建**，规格已定）
- 帧表：`{anim, fps, loop, sheet, frames:[{x,y,w,h,duration}]}`；测试期用序列帧目录，发布用打包产物

### 工序 5 · 生图通道

| 通道 | 能力 | 计费 | 用途 |
|---|---|---|---|
| MiniMax image-01 | 纯文生图（**无垫图**，接口已探针验证） | 按次 | 批量初稿/纹理 |
| FrameRonin 图生图（OT2.3 / 泰拉预设 / 地图拼接） | **垫图** ✓ 角色精灵表/场景/地图拼接 | 代充按次 | 风格锁定、定稿级素材 |
| pixel-snapper | 任意图 snap 网格+限色板 | 免费 | 对齐我们网格与色板 |

- MiniMax 调用：POST `api.minimaxi.com/v1/image_generation` Bearer Key，响应 `data.image_urls[]`
- 垫图：frameronin.com → RoninPro → 导入蓝图 `api-image-upload.json` → nano-banana-2 → 上传参考图

## 工艺纪律（生成/处理必守）

1. 上传 Figma/交付前先跑主色普查（防止彩虹噪点假图）
2. 解码 PNG 必须带完整滤镜处理（历史事故×3）
3. 老板 PS 定稿 = 权威版，AI 重生成不覆盖，只并排候选
4. 透明邻接的彩色格 → 描边；皮肤在头发正下方 → 加深
5. 对称角色先找对称轴再镜像；嘴用红系 FD4949/FE7171 放脸下部中心
6. 计费生成：先小样后批量；单张失败不整批重跑

## 排查速查

| 症状 | 原因 | 处理 |
|---|---|---|
| 图读出来是彩虹噪点 | 解码器缺滤镜处理 | 换带 f==1..4 分支的 decode |
| JPEG 读不了 | 纯 Python 解码器只吃 PNG | GDI+ 先转 PNG |
| 平铺有"井"字感 | 素材四边不匹配 | make-seamless2 重跑；或滑动选优切窗 |
| 40×40 出糊格子 | 步长跨源像素块 | 主色取样已内置；确认用了 craft 版 |
| MCP 连不上 | Git Bash 把 /c 转义成 C:/ | 改 .claude.json 的 args |
