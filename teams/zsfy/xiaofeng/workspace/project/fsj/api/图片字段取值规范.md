# 图片字段 URL 获取规范

> 所有明道云附件字段（图片/文件）统一按此方式取值

---

## 一、字段返回格式

明道云附件字段返回的是 **JSON 字符串数组**，需要先解析：

```javascript
// 字段值示例（字符串）
var field = '[{"file_id":"da0c0849-...","thumbnail_path":"https://p1.mingdaoyun.cn/doc/...","thumbnail_full_path":"https://p1.mingdaoyun.cn/doc/...?imageView2/1/w/200/h/118","large_thumbnail_full_path":"https://p1.mingdaoyun.cn/doc/...?imageView2/2/w/1280/h/800","file_path":"https://p1.mingdaoyun.cn/doc/...","file_name":"image.jpg","file_size":792574,"file_type":1,...}]';
```

## 二、标准取值方法

```javascript
/**
 * 从附件字段获取图片 URL
 * @param {string|Array} field - 附件字段值（字符串或数组）
 * @returns {string} 图片 URL
 */
function getImageUrl(field) {
  if (!field) return '';
  
  try {
    // 1. 如果是字符串，先 JSON.parse
    var data = typeof field === 'string' ? JSON.parse(field) : field;
    
    // 2. 取第一个文件对象
    if (Array.isArray(data) && data.length > 0) {
      var file = data[0];
      // 优先级：大图 > 缩略图 > 原路径
      return file.large_thumbnail_full_path 
          || file.thumbnail_full_path 
          || file.DownloadUrl 
          || (file.file_path + file.file_name) 
          || '';
    }
  } catch (e) {
    console.error('[getImageUrl] 解析失败:', e);
  }
  return '';
}
```

## 三、URL 类型说明

| 字段 | 用途 | 示例 |
|------|------|------|
| `thumbnail_full_path` | 小图（200x118） | `...?imageView2/1/w/200/h/118` |
| `large_thumbnail_full_path` | 大图（1280x800） | `...?imageView2/2/w/1280/h/800` |
| `DownloadUrl` | 原图（无压缩） | `.../image.jpg` |
| `file_path + file_name` | 原始路径拼接 | `https://p1.mingdaoyun.cn/doc/.../image.jpg` |

**推荐**：列表用小图 `thumbnail_full_path`，详情页用大图 `large_thumbnail_full_path`。

## 四、常见字段对照

| 场景 | 字段名 | 取值方式 |
|------|--------|---------|
| 文章主图 | `zhutu` | `getImageUrl(row.zhutu)` |
| 发布者头像 | `fbztx` | `getImageUrl(row.fbztx)` |
| 用户头像 | `avatar`（用户表） | `getImageUrl(row.avatar)` |
| 商品主图 | `zhutu` | `getImageUrl(row.zhutu)` |
| 轮播图 | 自定义配置 | `getImageUrl(item.image_url)` |

## 五、完整示例

```javascript
// 文章卡片渲染
var cover = getImageUrl(row.zhutu);
var authorAvatar = getImageUrl(row.fbztx) || 'assets/logo.png';

// HTML 模板
'<div class="post-card">' +
  '<img src="' + cover + '" alt="" />' +
  '<img class="author-avatar" src="' + authorAvatar + '" alt="" />' +
  '<span>' + authorName + '</span>' +
'</div>';
```

## 六、注意事项

1. **字段值是字符串**：API 返回的附件字段是 JSON 字符串，必须 `JSON.parse` 后才能访问属性
2. **数组取第一个**：附件字段是数组格式，通常只取 `data[0]`
3. **空值处理**：字段可能为空字符串或空数组，取值前必须判空
4. **CDN 域名**：所有图片 URL 都以 `https://p1.mingdaoyun.cn/` 开头
