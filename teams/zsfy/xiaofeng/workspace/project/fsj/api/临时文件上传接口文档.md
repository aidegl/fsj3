# 临时文件上传接口文档

> 用于需要临时存放文件（图片/PDF/Word等）、之后再上传到明道云等第三方平台的场景。
> 文件仅保留 10 分钟，之后自动清理。

## 基础信息

| 项目 | 值 |
|---|---|
| 基础 URL | `https://100000whys.cn` |
| 上传接口 | `POST /api/v1/temp/upload` |
| 文件访问 | `GET /temp/{filename}` |
| 清理接口 | `POST /api/v1/temp/cleanup` |
| Content-Type | `multipart/form-data` |
| 支持格式 | 图片(jpeg/png/gif/webp/svg)、PDF、Word(doc/docx)、纯文本 |
| 大小限制 | 10 MB |
| 保留时间 | 10 分钟（自动清理） |

---

## 1. 上传文件

```
POST https://100000whys.cn/api/v1/temp/upload
```

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | File | ✅ | 文件，字段名必须是 `file` |

**成功响应 (200)：**

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "url": "/temp/1780213606191_3spdv6.png",
    "filename": "1780213606191_3spdv6.png",
    "size": 5120,
    "mimetype": "image/png"
  }
}
```

**失败响应：**

| 场景 | code | message |
|---|---|---|
| 没传文件 | 400 | 请选择要上传的文件 |
| 格式不支持 | 400 | 不支持的文件格式 |
| 文件过大 | 400 | 文件过大，最大支持 10MB |

---

## 2. 访问文件

上传成功后，用返回的 `url` 拼接域名即可访问：

```
https://100000whys.cn/temp/1780213606191_3spdv6.png
```

## 3. 前端调用示例

### 基础 Fetch

```js
async function uploadFile(file) {
  const formData = new FormData();
  formData.append('file', file);

  const res = await fetch('https://100000whys.cn/api/v1/temp/upload', {
    method: 'POST',
    body: formData,
  });

  const result = await res.json();

  if (result.code === 200) {
    // 拿到临时 URL
    const tempUrl = `https://100000whys.cn${result.data.url}`;
    console.log('临时文件 URL:', tempUrl);
    return tempUrl;
  } else {
    throw new Error(result.message);
  }
}

// 使用
const fileInput = document.querySelector('#fileInput');
fileInput.addEventListener('change', async (e) => {
  const file = e.target.files[0];
  try {
    const url = await uploadFile(file);
    // 把 url 传给后端或上传到明道云
    console.log('可以用了:', url);
  } catch (err) {
    alert('上传失败: ' + err.message);
  }
});
```

## 4. webview-spa2.0 集成示例

在 webview-spa2.0 中，可以通过临时 URL 实现头像上传到明道云：

```js
// 步骤 1：选择本地图片
var input = document.createElement('input');
input.type = 'file';
input.accept = 'image/*';
input.onchange = function (e) {
  var file = e.target.files[0];
  if (!file) return;

  // 步骤 2：上传到临时接口
  var formData = new FormData();
  formData.append('file', file);

  fetch('https://100000whys.cn/api/v1/temp/upload', {
    method: 'POST',
    body: formData,
  })
  .then(function (res) { return res.json(); })
  .then(function (result) {
    if (result.code === 200) {
      // 步骤 3：拿到临时 URL，上传到明道云
      var tempUrl = 'https://100000whys.cn' + result.data.url;
      console.log('临时 URL:', tempUrl);

      // 步骤 4：用 Coze 工作流把临时 URL 上传到明道云
      // 注意：明道云附件字段需要传 JSON 数组格式
      var attachmentData = [{
        file_name: result.data.filename,
        file_path: tempUrl,
        file_size: result.data.size,
        file_type: 1
      }];

      // 调用 updateUserAvatar 或其他方法更新明道云
      // FsjApi.updateUserAvatar(userRowid, JSON.stringify(attachmentData));
    } else {
      alert('上传失败: ' + result.message);
    }
  })
  .catch(function (err) {
    console.error('上传出错:', err);
  });
};
input.click();
```

## 注意事项

1. **10 分钟有效期**：上传后请尽快把文件 URL 上传到明道云等平台，超时文件会被自动删除
2. **不需要鉴权**：直接调用即可
3. **文件名自动生成**：格式为 `时间戳_随机串.扩展名`，避免冲突
4. **清理接口**：`POST /api/v1/temp/cleanup` 可手动触发清理过期文件（前端不需要调用）
