## 一、需求定格（老板拍板）

| 项 | 结论 |
|---|---|
| 形态 | 安卓手机桌宠，悬浮窗常驻手机桌面 |
| 对话 | 文字为主 + 语音输入（语音转文字）；回答用文字气泡 |
| 大脑 | **HAP 明道云**做记忆/数据中枢 |

## 二、选型结论

| 项 | 选择 | 理由 |
|---|---|---|
| 平台 | **仅安卓，原生 Kotlin** | 悬浮窗(SYSTEM_ALERT_WINDOW)、前台服务、精确闹钟都是安卓一等公民；Flutter/RN 悬浮窗插件坑多；暂不做 iOS |
| UI | 传统 View + WindowManager 悬浮窗 | 悬浮窗场景经典 View 最稳；不折腾 Compose |
| 版本 | minSdk 26 / targetSdk 35 / AGP 8.5.2 / Kotlin 2.0.20 | Android 8.0+，覆盖主流机型 |
| 形象 | **Live2D Cubism SDK for Android** | 表情动作最丰富；SDK 到货前用占位形象（SimplePetRenderer）先跑通全链路，渲染器接口已预留，到时即插即换 |
| 对话 | 文字气泡 + 系统 SpeechRecognizer 语音输入 | 免费、零依赖；国产 ROM 无引擎时自动回退打字；后续可换讯飞 |
| 大脑 | **HAP 明道云** = 记忆/人设/提醒数据中枢 + 大模型 API 生成回复 | HAP 管数据，LLM 管生成，各司其职 |
| LLM | DeepSeek（OpenAI 兼容协议） | 便宜、中文好、直连可达；设置页可换成豆包/通义/GLM，改配置即可不用改代码 |
| 通道 | HAP 走现有 Node 代理 `100000whys.cn/mingdao`（密钥零落地）；LLM 由 APP 直连（自用，key 存手机本地） | 与团队「密钥零落地」纪律一致 |
| 提醒 | AlarmManager 精确闹钟 + 开机重排 | 系统级，App 被杀也能响；数据本地持久化，二期同步 HAP |
| TTS 语音播报 | 二期 | 先把文字链路跑通 |
| 包名 | `com.fsj.yeguo` | — |

## 四、Live2D 注意事项

1. **SDK 获取**：Live2D 官网下载「Cubism SDK for Android」，需在官网同意使用协议（免费版即够开发）。
2. **许可**：自用阶段免费；将来若产品化对外发布，需按官方「发布许可」协议办手续（到时再办）。
3. **过渡方案**：官方示例模型（如 Hiyori）可先用于开发调试；正式形象需要 Live2D 模型美术资源（可用作部位换装）。
4. **接入点**：`pet/PetRenderer.kt` 接口 + `CubismPetRenderer` 实现，上层零改动。

## 七、变更记录

- **2026-09-19（上线首日拍板）：语音方案调整**
  - **砍掉语音输入**：手机输入法自带语音识别（讯飞/搜狗键盘），APP 不重复做；本地 vosk 离线引擎在安卓 15+（16KB 分页）设备上存在官方未修复的兼容崩溃，一并移除，APK 从 85MB 瘦回 ~8MB
