## 一、数据字段

来自 [角色资产 JSON](../游戏资产.md)：

```json
{
  "dengji": 5,           // 当前等级
  "jingyan": 280,        // 当前累计经验
  "kaichangbai": "..."   // 开场白
}
```

HAP 用户表（69b0077358322d512e60bad0）里也有镜像字段：

```
'6a138efa86012aa0b85e996c' → dengji (数字)
'6a138efa86012aa0b85e996d' → jingyan 数字字段
'6a13012fcf4df8e5bc9a8a56' → 另一个 dengji 字段
'6a13897b2370499c8c419b85' → 另一个 jingyan
```

⚠️ HAP 里同名字段有 2 个，控制 id 不同——同步时取哪个需要确认（详见 [tech-style.md](../tech-style.md) 待补）。

## 四、增长规则（待定）

| 候选 | 说明 |
|----|----|
| 聊天次数 | 每说一句话 +1 经验，简单但粗糙 |
