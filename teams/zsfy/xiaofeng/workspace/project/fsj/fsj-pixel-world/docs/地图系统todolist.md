- [ ] 新建 `js/pages/map-editor/index.html / css / js`
- [ ] 顶部工具栏：返回 + 场景名 + 图层下拉 + 保存 + 发布

- [ ] 底部状态栏：模式 / 工具 / 坐标 / 积分
- [ ] 右侧属性面板：当前选中元素的属性

### P1.3 编辑操作

- [ ] 涂地皮（选瓦片 + 点格子）
