## C. 位置与世界形态 ⭐

**C1. "有他的所在位置"——位置意味着什么程度？**

- [ ] 静态驻点：每个角色有固定位置，像 NPC 站岗（如小风总在工坊门口）
- [ ] 驻点+待机动画：位置固定但有呼吸/眨眼等微动作
- [ ] 小范围活动：角色在驻点附近偶尔走动
- [x] 完全自主移动：角色按自己的"日程"在世界里活动（复杂度高很多）
- [x] 其他：地点不仅决定了角色的显示，在ui上需要。还有就是地点附带的信息，是一种场景，也决定了ai要怎么思考，也是让agent感知自己的，有活人感的一种形式

**C2. 位置由谁决定？**

- [ ] 我们后台配置（角色设定的一部分）
- [ ] 角色自己决定（AI 自主性的一部分，未来接 12 维记忆/计划）
- [ ] 用户放置（用户把自己的 AI 摆在家里）
- [ ] 其他：刚开始要么默认设定，后面他可以自己行动，或者被传呼

**C3. 世界有多大？MVP 的地图形态？**

- [ ] 单屏：一屏装下整个世界（最简单，类似老原型）
- [ ] 多屏滚动：世界比屏幕大，拖动/推动视角浏览（更像"世界"）
- [ ] 多场景+地图切换：世界分多个区域（广场/工坊/书房），点击地图入口跳转
- [ ] 其他：__人界就是地球，天界可以抽象一点就是一个平面有几个不同的场景分别为土局、火局、木局、金局、水局，这几个名字有点难听要想一想。每个局里面分别有个主管，也就是五个主神，他们分别带着各自的108将，还有东城的住所。分全景地图和进入后的样式，进入后地图比例变大了（人大小不变，但其实是相对变小了）因为全局地图只要显示重要信息，把场景细节都隐藏掉了。

**C4. 位置要不要在地图上有语义？**（比如小粽站在"总经理办公室"、阿说站在"书房"）

- [ ] 要，位置即职能，地图分区有含义
- [ ] 不要，先随机/好看就行
- [x] 其他：是动态的，可以灵活变化的
