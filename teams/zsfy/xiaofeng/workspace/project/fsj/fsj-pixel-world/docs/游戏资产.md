## 二、11 仓（财务系统/具象资源）v2026-09-02 更新

> 按 [12-dimensions.md](../12-dimensions.md)：
> **11 维（未·仓）= 财务系统/具象资源**（地皮、动物、食物等）

11 仓里的资产有**可量化价值**，可**流转（交易买卖）**。

### 2.1 与 3 维（业务）的关系

| 维度 | 含义 | 特点 | 流转性 |
|---|---|---|---|
| **11 仓** | 财务/具象资源 | 可量化价值 | ✅ 可交易 |
| **3 业务（巳）** | 服务/项目/无形资产 | 不可量化但能变现 | ⚠️ 需评估后流转 |

两者通过**交易/兑换**关联：
- 业务完成 → 兑换仓资产（按市场价）
- 仓资产可投资业务

### 2.2 11 仓资产种类（人间界）

> 商家 = 1 个世界，11 仓里的内容跟现实世界相似。

| 资产 | 性质 | 例子 |
|---|---|---|
| **地皮** | 地理/不动产 | 天孚宫(20,20)、土局1层入口 |
| **动物** | 活的生物（有状态）| 米鸡、头头 |
| **食物** | 消耗品 | 米、面粉、菜 |
| **材料** | 加工用 | 木头、石头、金属 |
| **工具** | 装备类 | 锤子、锄头 |

> ⚠️ 动物/食物是**有状态实例**（饥饱度、生长阶段），不能只存静态模板。
> 当前 11 仓只覆盖了**地皮**（地图编辑器那部分）；动物/食物等需要 M2+ 详设计。

### 2.3 资产流转（交易）

按 2026-09-02 东城定调：**流转 = 可交易买卖**。

存储策略：**全部走 shangpin 内容元数据**（不新建交易表），架构上更开放。

```
shangpin 行（sew=11 仓资产 / sew=10 交易流水 等关键词区分）
├─ mingcheng: 资产名/交易描述
├─ ptyh: 资产归属（角色 rowid）
├─ shangjia2: 所属商家
├─ guanjianci: [11仓资产关键词, 物品类型关键词, ...]
├─ shuzhi / jifen: 数量/价格
└─ 资产状态：持有/在途/已使用/...
```

具体字段设计待 M2 详谈。

## 三、调色板（`assets/color.json`）

```
11 列 × 10 行 = 110 色
第 1 行 = 灰度（E2E2E2 → 181818）
第 2-11 行 = 色系（红/粉/橙/黄/绿/青/蓝/紫/棕/...）
```

- **唯一颜色源**：所有像素画只能从这 110 色里取
- **约束纪律**：每个角色 ≤ 1 个色系行 + 灰度描边（避免颜色爆炸）

详见 [core / renderer.js](../../js/core/renderer.js) 与 [core/palette.js](../../js/core/palette.js)。

## 五、地图资产（场景 xsdt）

详见 [地图系统.md](./地图系统.md)。简言之：

```
xsdt (在 places.json / HAP 地点表)
├─ size: 48
├─ tilesize: 48
├─ tiles: { 'FFE6BB': [...16x16...], ... }      ← 瓦片库
├─ layers: {
│    ground[48][48]:     [tileId, tileId, null, ...]
│    decor[48][48]:      [tileId 或 null, ...]
│    collision[48][48]:  [0/1, ...]
│  }
├─ spawns: { nanmen:[{x,y}], ... }              ← 出生点
├─ entrances: [{tx,ty,to,label}]               ← 入口（跨场景跳转）
└─ miaoshu: "场景描述..."                       ← 喂 AI 的场景语义
```

**资产热替换**：换 JSON 文件即换场景，无需改代码。

## 七、资产生成管线

详见 [技术方案.md § 六](./技术方案.md)。简言之：

- **110 色调色板 + 16×16 二维数组** = LLM 擅长的格式化输出
- 输入：角色名/性格关键词/五行/主色系 → LLM 输出 16×16 数组（限定色系行+灰度）
- 校验：值域合法/描边闭合/主体连通/尺寸正确
- demo 期间：小风人工生成 6 个小人 + 1 个局的瓦片集
- 长期：AI 自主批量生成 + 校验器筛选
