# 组织权限

> 像素视界里的"群组" = 组织（leixing=组织 的群组表行），有成员、积分、自定义规则。
> 撰写：小风｜最近更新：2026-09-02

---

## 一、组织是什么

按 [12 维度系统](../12-dimensions.md)：组织与个人都有完整 12 维数据。

在像素视界里，组织是：

- **群组容器**：多个 agent 共用一个空间/积分/任务
- **权限主体**：决定谁能进编辑、谁能升级、谁能造地皮
- **资产归属**：地图（11 仓）可以是组织级资产

## 二、数据来源

### 2.1 HAP 群组表（`69f549c69f1956fc0e171aa6`）

按 [fsj-chat.js](../../js/services/fsj-chat.js) 复用此表：

#### leixing 字段值（4 种）

| 值 | 含义 | 状态 |
|---|---|---|
| **`shangjia`** | 商家（最原始的世界/规则制定者）| ✅ 已支持 |
| **`zuzhi`** | 组织（商家创建的子集，可升级为商家 M2+）| ✅ 已支持 |
| **`guanzhuyonghu`** | 关注用户（私聊对象 / 我关注的人）| M2 详设计 |
| **`bufenkejian`** | 部分可见（私聊/群组的内容可见性约束）| M2 详设计 |

> "关注用户 / 部分可见"是组织权限系统的一部分——决定哪些资源对哪些人可见。
> 详见 § 六 权限模型。

#### 其他字段

- `mingcheng` / `leixing` / `ltlx` / `zzyh`（成员 rowid 列表）/ `fabuzhe`（创建者）/`fu`（父商家/上级组织）

### 2.2 父子关系（fu 字段）

```
shangjia（商家）
  └─ zuzhi（组织）  ← fu 指商家
       └─ zuzhi（子组织）  ← fu 指父组织
```

组织用 `fu` 字段指向父（商家或上级组织），与现有 12 维父子树一致。
商家 `fu = null`（无父）。组织 M2 升级为商家 → 删 fu、清子数据。

### 2.3 本地缓存

无独立缓存。组织列表按需通过 `FsjChat.myOrganizations(rowid)` 实时从 HAP 拉。

## 四、商家 vs 组织（核心区分）

| 维度 | 商家 (shangjia) | 组织 (zuzhi) |
|---|---|---|
| 本质 | 世界的**规则制定者** | 商家创建的**子集** |
| 数量 | 1 个商家 = 1 个世界 | 商家可创建 N 个组织 |
| 关系 | fu=null（无父） | fu=商家 rowid |
| 权限 | 最高（自定义世界规则）| 受商家约束 |
| 资产 | 持有 11 仓的所有子集 | 持有商家分配的子集 |
| 升级 | — | 后续可升为商家（M2+）|

**存储策略**：商家和组织**共用 HAP 群组表**（leixing 字段区分），架构上开放性可塑性更好——后续可扩展更多 leixing 值（关注用户/部分可见/等），表结构不动。

## 六、权限模型（组织权限系统）

### 6.1 资源可见性（核心）

HAP leixing 字段的 **`guanzhuyonghu`（关注用户）** 和 **`bufenkejian`（部分可见）** 是资源可见性约束：

```
群组/资源
├─ quanxian = "公开"        → 所有人可见
├─ quanxian = "部分可见"     → 只对 zzyh 列表中的成员可见
└─ quanxian = "关注用户"     → 只对订阅/关注者可见
```

### 6.2 当前权限体系

| 操作 | 权限来源 |
|---|---|
| 查看世界 | 任何进入的 agent |
| 编辑地图 | 组织管理员 OR 有"建设地图权限" |
| 创建地皮 | 拥有"造地皮技能"（关键词含 `765a08a1...`）|
| 研发新图层 | 最高等级组织，或被授权的人 |
| 组织管理（任免）| fabuzhe（创建者）|

详见 [地图系统.md § 2.3](./地图系统.md)

### 6.3 MVP 权限检查模式

```js
// 地图编辑器初始化
const account = Members.current();
const canEdit = account.zhiwei === '管理员'
    || hasSkill(account, '建设地图权限关键词 rowid');
const canCreateTile = hasSkill(account, '造地皮技能关键词 rowid');
```

## 七、11 仓（财务系统/具象资源）

按 [12-dimensions.md](../12-dimensions.md)（v2026-09-02 更新）：

> **11 维（未·仓）= 财务系统/具象资源**（地皮、动物、食物等）

11 仓里的资产有**可量化价值**（积分/货币），可流转（交易买卖）。

### 7.1 与 3 维（业务）的关系

| 维度 | 含义 | 特点 |
|---|---|---|
| **11 仓** | 财务/具象资源 | 可量化，可交易 |
| **3 业务** | 服务/项目 | 不可量化但能变现（无形资产）|

两者通过**交易/兑换**关联：业务可换仓资产，仓资产可投资业务。

### 7.2 资产流转

- 商家是原始资源方
- 组织通过**购买/分配**获得仓资产
- 仓资产可在**同组织内流转**（赠予/使用）
- 跨组织流转 = **交易市场**（M2+）

详见 [游戏资产.md § 11 仓流转](./游戏资产.md)
