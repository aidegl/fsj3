## 一、技能是什么

按 [12 维度系统](../12-dimensions.md)（来自 `.claude/memory/12-dimensions.md`）：

> **1 维（寅）= 技能**：Skill技能表

即 HAP 内容元数据（shangpin）中，**关键词 + 类型标记为"知识 + 1技能"** 的条目。

---

## 二、数据来源

### 2.1 HAP 内容元数据表（shangpin）

- 关键词字段含 `sew=1技能` 分类
- fabuzhe（发布者）字段 = 拥有此技能的角色 rowid
- 详细同步逻辑见 [sync-hap-data.js](../../tools/sync-hap-data.js)

### 2.2 本地缓存：`assets/skills.json`

`tools/sync-hap-data.js` 同步出：

```json
{
  "<rowid>": [
    {
      "rowid": "<skill rowid>",
      "mingcheng": "技能名",
      "sew": "1技能",
      "xstb": [...16x16 像素图标...]
    },
    ...
  ],
  ...
}
```

按账号 rowid 分组。
