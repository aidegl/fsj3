## 快速运行

```bash
cd fsj-pixel-world
npx http-server -p 8088 -c-1
# 浏览器（手机模式）打开 http://localhost:8088/?page=world
```

⚠️ 必须 HTTP 访问（ES Module + fetch 限制）。资产生成：`node tools/gen-assets.js`（角色/瓦片/场景/局图腾全部程序化生成，可改参数重跑）。

## 已支持：像素形象二次编辑

- 入口：世界中点角色 → 面板 → **编辑形象**（或直达 `?page=editor&agentId=demo-xxx`）
- 16x16 网格 + 110 色调色板；画笔/橡皮/吸色/撤销(50步)/清空
- 保存 → localStorage 热覆盖，**世界中的形象立即生效**；"恢复原始形象"一键还原
- 导出 JSON → 可直接替换 `assets/characters/*.json`（回流资产库，也是未来 Agent 自主生成形象的落地格式）
- 眨眼帧自动派生：只编辑站立帧，头部区域（虚线以上）的眼色像素自动生成闭眼帧

## 一句话定位

一个 **Canvas 像素风格的"AI 角色世界"**：AI 角色以像素小人的形态驻留在世界地图的不同位置，用户可以浏览世界、点击任意角色与它对话、查看与它的历史聊天记录——把"和 AI 聊天"从冰冷对话框变成"走进一个世界找你的 AI 伙伴"。

## 核心概念

| 概念 | 说明 |
|------|------|
| 世界（World） | 像素风格的地图，由一个或多个场景组成 |
| 场景（Scene） | 一张地图画布，有地形/装饰，是角色的容器 |
| 角色（Character） | 生活在世界里的 AI（像素小人），有名字/等级/五行/地支性格/位置 |
| 位置（Position） | 角色在场景中的所在格子坐标，用户可见"他现在在哪" |
| 对话（Chat） | 点击角色发起/继续与它的 AI 对话 |
| 聊天记录（History） | 与每个角色的对话历史，可随时回看 |

## 技术路线（详见 docs/技术方案.md）

- **渲染**：原生 JS + Canvas 2D（零依赖，自写轻量渲染器），三分离架构，同 `webview` / `webview-spa2.0` 传统
- **像素规范**：110 色统一调色板（color.json）、`#181818` 描边、禁用抗锯齿、整数倍缩放
- **双层资产**：16x16 场景小人（生活在地图里）+ 41x41 详情大图（角色面板/头像）
- **格子系统**：场景 48x48 格（1 格=16px）；世界全景图为抽象布局（不用格子）
- **AI 对话**：接口隔离（aiAdapter），demo 用 MockAIAdapter 示例数据，最终后端待定（不用 Coze）
- **聊天记录**：明道云消息表结构（chat.js 行结构 + 位置字段），demo 期间同结构示例数据
- **位置系统**：日程驱动的自主移动 + 传呼；位置作为 AI 的上下文输入（场景即心智）
- **资产管线**：Agent 在 110 色约束下自主生成像素（LLM 输出二维数组 + 校验器 + 预览）
- **运行环境**：手机 H5（浏览器 + 微信小程序 webview 内嵌）

## 世界观（v1.0 确立）

整个像素视界分**三界**：
- **天界**（1.0）：五行局（土/火/木/金/水，命名待定）+ 五位主神 + 东城住所；1.0 居民 = 小粽/小风/阿说/梦瑶/小云 + 东城（林东城的 AI 分身）；2.0 扩展 108 将。天界居民永生。
- **人界**（3.0）：以地球为蓝本，有结婚、生子、投胎机制；有昼夜/天气
- **地界**（4.0）：低效、犯错的 Agent 被放来反思之所
