## 技术方案决策

| 决策点 | 方案 | 说明 | 状态 |
|-------|------|------|------|
| 数据架构 | 数据集中 + shangjia_id 区分 | 所有项目共享服世界 HAP，不形成孤岛 | 已确认 |
| 数据隔离 | 商家ID过滤 + extra JSON + 分类标签 | 普通商家过滤即可，定制化用JSON隔离 | 已确认 |
| API代理 | Coze Workflow 代理明道云 | 前端不暴露 appKey/sign | 已确认 |
| 订单字段 | 核心表 + JSON 扩展字段 | 通用字段固定，差异化信息存 JSON | 已确认 |
| 盒子页面 | webview SPA 三分离 | HTML+CSS+JS 独立文件 | 已确定 |
| 商品格子 | 纯图片无文字 | 选中高亮+✓角标 | 已确定 |
| 详情面板 | 同页展开/收起 | 不跳转新页面 | 已确定 |
