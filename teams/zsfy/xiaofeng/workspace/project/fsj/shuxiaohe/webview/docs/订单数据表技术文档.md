## 二、Coze API 调用方式

### 1. API 配置

```javascript
{
  url: 'https://api.coze.cn/v1/workflow/stream_run',
  token: 'sat_PsqZd6JJl9qOPZoT30rPv2gLKAVIMXGMmIp38VzXXIRU77nzgzk09yvcFwNT8Z4h',
}
```

### 2. 通用增删改查参数

| 参数 | 说明 |
|------|------|
| worksheetId | 表ID |
| fieldAlias | 字段别名列表（逗号分隔） |
| filter | 查询条件（JSON 字符串） |
| data | 新增/更新数据（JSON 字符串） |

### 3. 订单创建流程

```
1. 前端收集购物车数据 → 构建订单数据
2. 先创建订单主记录 → 返回订单 rowid
3. 批量创建订单明细 → 关联到订单 rowid
4. 调起微信支付（如有剩余金额）
5. 支付成功后更新订单状态
```

## 三、状态枚举值

### 订单状态 (zhuangtai)
- 待支付
- 已支付
- 配送中
- 已完成
- 已取消

### 付款方式 (fkfs)
- 盒子价先享后付
- 余额支付
- 微信支付
- 余额+微信支付

---

## 四、注意事项

1. 创建订单明细前需先创建订单主记录，拿到订单 rowid 后关联
2. 关联记录字段需传入目标表的 rowid
3. 金额字段传入数字类型，不要传字符串
4. 批量创建订单明细可用批量新增接口
