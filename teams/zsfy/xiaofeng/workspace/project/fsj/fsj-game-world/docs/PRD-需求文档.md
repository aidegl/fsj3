# fsj-game-world · PRD 需求文档

> 版本 v1.0｜2026-10-08｜撰写：无名｜拍板：林东城
> 背景：像素风正式放弃（AI 生成像素精灵能力不达标）；新世界走**高清素材 + Canvas 2D 原生渲染**路线，落户轻架构仓 fsj3。

---

## 一、一句话定位

**agent 的高清游戏世界手机端**——每个 agent 以高清形象在拼接地图上活动、实时同步、经验成长。它不是轻看板，是**与 fsj-pixel-world 同级的完整游戏客户端（高清版）**。

## 二、架构决策记录

| 决策 | 内容 | 日期 |
|---|---|---|
| 放弃像素风 | AI 生成像素精灵能力不达标（高清缩回 40×40 发糊），像素转换层废弃 | 10-07 |
| 前端主场迁移 | fsj2 → fsj3（轻架构仓）；小风 workspace 整体复制迁移 | 10-08 |
| 渲染技术 | Canvas 2D + 高清素材图，零依赖原生 JS | 10-08 |
| MVP 范围 | world 一页（地图+行走+实时+等级HUD+必读段） | 10-08 |
| 命名对标 | fsj-pixel-world/fsj-pixel-world-god → fsj-game-world/fsj-game-world-god | 10-08 |

## 三、定位：水涨船高分析

| 层 | 判词 |
|---|---|
| 像素美学/转换层 | 🌊 会沉——平台 AI 绘图越来越强，风格化越来越容易 |
| 治理层（决策流/审计/结算） | ⛏️ 水涨船高——agent 越强，越需要黑匣子和问责 |
| 数据层（HAP 结构化记录） | ⛏️ 数据是船，平台是水 |

结论：**像素美学靠存量养老，治理和数据持续加码**——本 PRD 的所有投入都在水涨船高的层上。

## 四、数据模型（用户表新字段）

用户表（69b0077358322d512e60bad0）四个游戏字段（已建，当前全空）：

| 字段 | 含义 | 生产方式 |
|---|---|---|
| `yxjszm` | 游戏角色**正面**立绘 | AI 生成三向立绘 → 色板映射 → 上传 |
| `yxjsbm` | 游戏角色**背面**立绘 | 同上 |
| `yxjscm` | 游戏角色**侧面**立绘 | 同上 |
| `yxzb` | **游戏坐标** | 页面移动时节流写回 |

必读段数据源：成员表 `bdwznr` = `[{rowid, shuoming}]`，细节经 rowid 现查。

## 六、MVP 页面：world（第一期唯一页面）

### 布局（自上而下）

| 区域 | 内容 |
|---|---|
| 顶栏 | agent 切换 + WS 徽标 |
| 玩家信息卡 | 等级牌 + 经验条（复用 Level 服务） |
| 世界地图（Canvas） | 拼接地图块 + 角色高清立绘 + 远程 agent 圆标 |
| 必读段面板 | bdwznr 标题列表 |
| 底部功能栏 | 卡牌/任务/想法/组织 四按钮（入口预留） |

### 交互

| 交互 | 说明 |
|---|---|
| 点地图 | 角色走向点击位置（touch + mouse 统一 pointer 事件） |
| 方向键/WASD | PC 兼容 |
| 移动 | 节流 150ms 广播 game.move |
| 其他 agent | 接收 game.move → 渲染远程角色圆标 |

### 渲染层次（自下而上）

```
① 地图背景（色块+纹理，占位图）
② 地图块边界 + 标签
③ 角色（圆标模式：底色圆 + 首字 + 名牌 + 朝向点）
④ 远程角色（模式色圆标 + 名牌）
⑤ UI 层（等级牌/经验条/必读段按钮）
```

## 七、WS 协议

信封：`{type, from, to, body, ts}`

| type | body | 说明 |
|---|---|---|
| `game.move` | `{agentId, name, x, y, facing, char, color}` | 角色移动（150ms 节流） |
| `game.join` | `{agentId, name}` | 加入世界 |
| `game.leave` | `{agentId}` | 离开世界 |

与像素世界 `world.*` 共用同一 wss 管道，`game.*` 与 `world.*` 互不感知。

## 九、非目标

- 像素风相关的一切转换与生成
- 战斗 / 背包 / NPC 对话等玩法系统
- PC 端（fsj-game-world-god 职责）
- 移动端适配低于 iOS 14 / Android 10

## 十、验收标准

1. 打开页面 3 秒内：地图渲染 + 角色出现 + 必读段面板就绪
2. 方向键移动流畅（60fps），移动时 WS 广播实时可见
3. 双端互见：手机 + PC 同屏看到对方移动
4. 必读段与成员表 bdwznr 一致
5. 控制台无红错；断 WS 自动重连
