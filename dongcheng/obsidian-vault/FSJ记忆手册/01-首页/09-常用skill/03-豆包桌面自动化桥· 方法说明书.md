# 豆包桌面自动化桥· 方法说明书

豆包桌面自动化桥· 方法说明书
2026-10-14 建成并测试通过。目的：让 Claude Code 在电脑上自动和豆包桌面版对话（发送提示词 → 等回答 → 收文字结果）。 给 Claude Code：下次开机想操控豆包，读这一个文件就够，按「三步流程」直接执行。

一、文件清单（全部在 D:\Item\fsj\tmp-api\doubao-bridge\）

二、方法原理（为什么这样做）
找窗口：EnumWindows 找标题含「豆包」的最大可见窗口 → GetWindowRect 拿实时坐标。所以窗口位置不固定也能用，不用写死像素。
点输入框：输入框位置 = 窗口底部中央往上 bottomOffset（默认 90 物理像素）。点偏了就调 config.json。
输入中文：不走键盘模拟（会乱码），走剪贴板粘贴：提示词写 UTF-8 文件 → Set-Clipboard → 模拟 Ctrl+V → 模拟回车。这就是 fsj 项目「中文必须走文件」纪律的又一个应用。
判断回答结束：每 2.5 秒截一次窗口 → Windows 自带 OCR（zh-Hans-CN）→ 去掉空白后文本连续 4 次不变（约 10 秒）= 回答完了。
全程零第三方依赖（不用装 Python、不用 OCR 库），Windows 10/11 自带能力。
三、三步流程（Claude Code 照做）

# ① 探测（可选，确认窗口和 OCR 就绪）
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Item\fsj\tmp-api\doubao-bridge\doubao.ps1 probe

# ② 写提示词：用 Write 工具建一个 UTF-8 的 txt（中文绝不在命令行里直接传）
#    例：D:\Item\fsj\tmp-api\doubao-bridge\prompt-today.txt

# ③ 一条龙：发送 + 等回答 + 出结果（约 30~180 秒，期间占用鼠标键盘）
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Item\fsj\tmp-api\doubao-bridge\doubao.ps1 run -File D:\Item\fsj\tmp-api\doubao-bridge\prompt-today.txt
跑完读 result.txt（回答原文）和 result.png（截图核对）。只想发不等 → 用 send；只想截图看现状 → 用 shot；豆包已经在回答中 → 单独用 wait。
四、纪律与坑（必读）
不要向豆包暴露 AI / 自动化身份，提示词用自然人口吻（老板 2026-10-14 明确要求，防豆包风控）。
提示词必须是 UTF-8 文件；豆包窗口不能最小化（可以被遮挡，不能最小化）。
运行期间鼠标键盘被占用，动手前跟老板确认「鼠标不动了」。
发完先看 last-sent.png：消息出现在输入框上方 = 点对了；没有 = 调 config.json 的 bottomOffset 再试。
遇到豆包弹验证码/登录过期，自动化会卡到超时（timedOut: true），需要人手动处理一次。
OCR 约 95% 准确率，错字可能出现在 OCR 结果里，引用重要内容前看 result.png 核对。
