# Figma制作复杂技术概念讲解图

Figma制作复杂技术概念讲解图
[[[a2a]]]
概念图解术：复杂技术概念 → 一页 Figma 讲解图
核心原则：先想清楚「讲什么给谁听」，再动手画。 比喻定骨架，结构定逻辑，色彩定语义，工具只是把想清楚的画出来。
第〇步：四问（答不出就别动手）
让谁一眼看懂什么？——压不成一句总纲就还没想清楚
每个抽象概念的生活对应物是什么？
概念之间是并列、分层、流程还是循环？
读者视线从哪到哪？（竖版 = 从上往下讲故事）
第一步：压缩 —— 概念清单 → 5-7 块
全图 = 总纲条 + 1 个主体模式 + 0-3 个辅助行。每块只讲一个思想。 按概念间的关系选结构模式：

第二步：翻译 —— 抽象阶梯
每个抽象概念向下找一个生活对应物（命名空间→电网电压国标；缓存→寄存行李）
比喻成套：选了「家」就一路家居语汇，不串第二个域
每格文字 ≤3 行：术语一行 + 白话一行，永远成对
例外：形式化程度高的概念（协议字段、公式）不硬配比喻，用结构本身说话
第三步：视觉语言
色彩即语义，一色一义全页一致。默认：青=个体/自由、绿=组织/合规、橙=底座/公共、 蓝=规范/流程、紫=演化/循环、红=边界/禁改、黄=总纲/金句。 若目标文件已有页面/团队设计语言，沿用它的语义，不引入第二套
字号三级：页题 38-40 / 节题 22 / 正文 12.5-15；深底 #0C0A12、卡片 #16131F（新文件默认，跟随已有页面则以其为准）
每块一个强调色描边卡；正文白、注释灰
第四步：Figma 施工（use_figma 通用硬坑）
文字换行：先 resize(w,10) 再 textAutoResize='HEIGHT'，顺序反了高度卡死
所有容器 fills=[]（Frame 默认白底，忘设=开花）
先 appendChild 再设 layoutSizingHorizontal='FILL'；且 父链每一层都要 FILL，漏层=塌成细条
根容器 resize(W,100) 后必须 primaryAxisSizingMode='AUTO'
出错整笔回滚：按 band 分 1-2 次调用，别一把梭
建完必 get_screenshot 三查：裁字 / 白底 / 塌缩；修完再截，末张通过即收工
每次调用返回 createdNodeIds，修图按 ID 定点打
第五步：验收
三查通过（裁字/白底/塌缩）
外行凭总纲能复述主线
比喻成套无串戏
颜色语义全页一致
30 秒从上往下能讲完
