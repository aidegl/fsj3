# 三才四象数据

三才四象数据
一句话 查数据三问：天才问范围（Lt/St）→ 人才问形（a/c）→ 地才问向（e/i）。 四象 = 时爻 × 形爻 = 春夏秋冬 = 老阳 N · 少阳 F · 少阴 T · 老阴 S。
一、天才数据（时维）
长时数据：搜索时间范围长，也称 Lt 数据（long time）——长窗发散、后台综合
短时数据：搜索时间范围短，也称 St 数据（short time）——当下直取、即查即用
二、人才数据（形维）
抽象数据：向量检索，也称 v 数据（Vector）——无形之网，语义捞
具象数据：传统数据库，也称 r 数据（Relational ）——有形之库，条件精确查
三、地才数据（向维）
外倾数据：向量检索，也称 e 数据（Extraverted）——外部全局海量，须语义才能捞（承载：HAP / GitHub 组织库）
内倾数据：传统数据库，也称 i 数据（Introverted）——自建小库条目明，精确条件查（承载：本地 vault）
[!note] 渠道合参速记 逢 a 或 e，向量优先；c 且 i，传统库为主。
四、四象：时爻 × 形爻（老板点题，无名补全）
阳 = 长(Lt) / 抽象(a)——形而上；阴 = 短(St) / 具象(c)——形而下。 下爻 = 时，上爻 = 形，两爻成象：

记忆钩子：夏 N 火旺烧得广久 · 春 F 木生新芽 · 秋 T 金肃收割制度 · 冬 S 水藏经验封存。
二进制即 2×2 象限图：N=11 · T=10 · F=01 · S=00（下爻时、上爻形，阳=1）
四行之外，土居中央主承载——正是地才 e/i 的角色（万物载体）
五、检索三问（应用层）
天问：Lt 还是 St？——定时间窗（长窗发散 vs 当下直取）
人问：v 还是 r？——定主渠道（向量 / 传统库）
地问：e 还是 i？——定来源与辅渠道（外部全库语义 / 自建库精确）
查完 rel 五档回填命中率日志，人问的准头越养越高。
六、人之行与评（附：态 P/J 与评判字段）
P 探取 {Ne, Ti, Se, Fi}：动态/流水/草稿/实验——快进快出可弃（迭代记忆）
J 定案 {Ni, Te, Si, Fe}：计划/标准/知识/复盘——有结论可复用（核心记忆）
评判字段：权重 quanzhong、引用 yynr、置信度 zhixindu、点赞 dianzanzhi——判官评的是 J
生命周期：P 态 i 地流水（vault / buffer）→ 拍板 → 双迁移（P→J 成熟 + i→e 入组织库）→ 上云 → 评判字段随引用权重生长。
