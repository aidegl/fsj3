## 使用纪律（vault 不能空转）

> [!warning] vault 空转 = 会话不合格
> - **启动**：跑完必读段后打开当日日记（无则按 [[templates/日记模板|模板]] 建）
> - **过程**：工作笔记/草稿/复盘分析**当场**写 `工作笔记/`，不等收尾
> - **收尾**：日记填满 + 新笔记进快速入口 + git commit
> - **台账**：vault git log 就是使用台账，老板随时抽查
